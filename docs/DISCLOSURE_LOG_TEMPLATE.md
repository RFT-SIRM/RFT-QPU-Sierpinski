# Disclosure log — template

**Purpose:** maintain a dated record of any disclosure that may affect patent novelty, trade-secret status or partner confidentiality.

This file is intentionally a template. No disclosure chronology has been verified by this repository review. An empty table is not evidence that no disclosure occurred.

## Entry fields

For every disclosure, record:

| Field | What to enter |
|---|---|
| Date and time | Exact date/time and timezone |
| Material version | Commit SHA, document revision, deck version, screenshot or attachment hash |
| Recipient(s) | Names, organisations and roles |
| Channel | Meeting, email, website, GitHub, presentation, paper, demo, messaging or other |
| Content disclosed | Exact technical scope; attach the version shown |
| Public or confidential | Public, non-public, NDA-covered, professional confidentiality or uncertain |
| Agreement | NDA/contract name, signed date, parties and file reference |
| Enabling detail | Whether the inventive technical features were disclosed |
| Evidence retained | Email, meeting notes, signed agreement, access record or publication URL |
| Counsel action | Patent attorney's view and next step |

|---|---|---|---|---|

## Immediate review checklist

- [ ] Review all prior repositories, tags, branches, mirrors and public archives.
- [ ] Review any GitHub Pages, website, downloadable package or public file share.
- [ ] Review papers, preprints, abstracts, talks, posters and competitions.
- [ ] Review emails, investor calls, supplier discussions and demonstrations.
- [ ] Record whether any recipient had a legally binding confidentiality duty.
- [ ] Ask patent counsel to assess each event by date, jurisdiction and disclosed technical content.

Do not write “no prior disclosure” until the chronology has been checked against records outside this repository.
